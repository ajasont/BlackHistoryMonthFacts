# Black History Facts

600 curated facts celebrating Black excellence, history, and culture — available as a web app and an iOS widget.

**Live site:** https://ajasont.github.io/BlackHistoryMonthFacts/

---

## iOS Widget (Scriptable)

Displays a new fact every day on your iPhone Home Screen or Lock Screen. No App Store submission, no developer account required.

### Setup

1. Install **[Scriptable](https://apps.apple.com/us/app/scriptable/id1405459188)** (free) from the App Store.
2. Open Scriptable → tap **+** (top right) → paste the entire contents of [`widget.js`](widget.js) → tap **Done**.
3. Name the script (e.g. *Black History Facts*).
4. Long-press your Home Screen → tap **+** → search for **Scriptable** → choose **Small**, **Medium**, or **Large** → tap **Add Widget**.
5. Long-press the new widget → **Edit Widget** → set **Script** to *Black History Facts*.

The widget shows a new fact each day and taps through to the full web app.

### Widget sizes

| Size | Behavior |
|------|----------|
| Small | Category label + shortened fact |
| Medium | Category label + full fact (most cases) |
| Large | Full fact with extra breathing room |

## Web App

Open `index.html` in any browser or visit the GitHub Pages link above. Features:

- Browse all **600 facts** across 22 categories
- Filter by category
- Prev / Next / Random navigation
- Progress tracker (facts discovered)
- Keyboard shortcuts: `←` `→` `Space` to navigate, `R` for random
